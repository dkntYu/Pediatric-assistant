# 兒科口袋助手

資料整理版 v0.3，2026-10-27。個人臺灣臨床工作助手的開發版本，未經院內醫師／藥師臨床驗收。

## 開啟
用 Chrome／Edge 直接開啟 `dist/index.html`。外部字型、CDN、即時AI均未使用，核心資料與算式位於本地檔案；來源連結需要網路。已加入PWA快取與手動版本更新，邏輯測試通過；手機安裝與實際飛航使用另待驗證，不能視為已通過iPhone離線驗收。

## 使用
1. 選早產兒／新生兒／嬰兒／兒童，輸入年齡及kg體重（最多一位小數）。出生0–28天用新生兒分類；早產兒同時填出生胎齡與日齡。未滿18歲。
2. 按「套用資料」，選四區之一，搜尋並展開項目。
3. 藥物先選用途／途徑，再填選用每公斤劑量與實際已備藥液的最終濃度。單位明列，不可把mg/mL輸入μg/mL欄。
4. 有稀釋配方者再輸入實際原液濃度，必須與已整理配方一致；未知配方不猜測。尚無配方者只換算實際已配液體積，不代表已確認相容性。
5. 結果附計算過程與來源。修改病人資料後舊結果失效；先重新套用。
6. ☆常用只存本次開啟期間，重新整理即清除；不儲存病人資料。

## 範圍與限制
- 27藥物條目（含新增Naloxone），59個來源明確的用途／給藥模式。Propacetamol與Parecoxib有明確停用原因，不以成人或相似藥物補算。
- 已包含部分早產／新生兒模式，不代表所有藥物、胎齡、日齡都有來源或可計算。來源不足者停止計算。
- 氣管內管、喉頭鏡及特定廠牌LMA供準備估計。口／鼻咽呼吸道顯示量測法；較大兒童鼻管深度不臆造。新生兒表需胎齡與體重符合，否則停止。
- 輸液：非新生兒維持量、一次補液、實測流失。另有特定適用條件的新生兒總液體量，不能泛用於NICU。
- 輸血：兒科Hb增幅與血品mL/kg；新生兒另按專用來源。處方時間需人工決定，不直接換算臺灣血品單位。
- 不是完整藥物手冊、復甦流程或處方系統。尚無每日累積劑量追蹤、所有交互作用／禁忌、自動腎調整、幫浦刻度取整、完整管路相容性與長期穩定性資料。

## 驗證
```
node test-clinical.cjs
node test-infusion.cjs
node test-ui.cjs
node test-offline.cjs
node --check dist/app-v3.js
node --check dist/clinical-ui.js
```
測試確認算術、來源資料結構與限制，不能代替臨床驗收。來源索引於 `dist/clinical-data.js`，詳細差異與待辦見 `SOURCES.md`、`PROGRESS.md`。

`test-ui.cjs`使用本地測試依賴 `.qa/node_modules/jsdom`；可用 `npm.cmd install --prefix .qa jsdom --no-audit --no-fund` 安裝。該套件不隨網站發布、不在使用時呼叫網路。其他測試只需Node.js。

# v0.6 使用方式（優先於下方歷史版本說明）

套用年齡與體重後，卡片直接顯示適用的IV建議用量範圍，無須先選劑量或按計算。單次與持續輸注分開顯示；有來源配方時列出對應體積／速率與濃度假設。公式、來源及個別濃度換算放在展開說明。PO與IM模式不列入本版介面，原始資料保留。來源不足仍明確標示。

驗證：`node test-clinical.cjs`、`node test-ui.cjs`、`node test-recommendations.cjs`、`node test-offline.cjs`。DOM與快取測試不等於手機實機驗證。
