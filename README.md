# 兒科口袋助手

## 最新：v0.4 計算機模式

依使用者2026-10-27要求改為自行輸入的算術工具：不需要逐項勾選確認；27個藥物都可自由輸入劑量、濃度與單位。沒有參考劑量的藥物不預填數字，但仍可依使用者自行輸入換算。

- 單次量、mL、mL/hr；支援mg/μg濃度互換及每分鐘／每小時。
- 稀釋：填原液濃度與配製後總體積，使用C₁V₁=C₂V₂；不自行選稀釋液或斷定相容性。
- 參考範圍、年齡與來源上限僅作提示，不阻擋算術，也不自動截限或提高輸入劑量。
- 輸液／血品可自行輸入mL/kg、總mL及時間；紅血球另有Hb增幅公式。
- 仍拒絕負數、0作除數、無效值與mmol↔mg等無依據量綱互換。
- 最新入口仍為dist/index.html；新增dist/calculator.js覆蓋v0.3藥物與體積介面。

目前應執行：`node test-calculator.cjs`、`node test-offline.cjs`。`test-clinical.cjs`與`test-ui.cjs`保留v0.3的自動截限／臨床阻擋假設，**不適用於v0.4**；不能將其舊版結果當作v0.4測試結果。

## 使用
1. 選早產兒／新生兒／嬰兒／兒童，輸入年齡及kg體重（最多一位小數）。出生0–28天用新生兒分類；早產兒同時填出生胎齡與日齡。未滿18歲。
2. 按「套用資料」，選四區之一，搜尋並展開項目。
3. 藥物先選用途／途徑，再填選用每公斤劑量與實際已備藥液的最終濃度。單位明列，不可把mg/mL輸入μg/mL欄。
4. 有稀釋配方者再輸入實際原液濃度，必須與已整理配方一致；未知配方不猜測。尚無配方者只換算實際已配液體積，不代表已確認相容性。
5. 結果附計算過程與來源。修改病人資料後舊結果失效；先重新套用。
6. ☆常用只存本次開啟期間，重新整理即清除；不儲存病人資料。

## 範圍與限制
- 27藥物條目（含新增Naloxone），59個來源明確的用途／給藥模式。Propacetamol與Parecoxib有明確停用原因，不以成人或相似藥物補算。
- 已包含部分早產／新生兒模式，不代表所有藥物、胎齡、日齡都有來源或可計算。來源不足者停止計算。
- 氣管內管、喉頭鏡及特定廠牌LMA供準備估計。口／鼻咽呼吸道顯示量測法；較大兒童鼻管深度不臆造。新生兒表需胎齡與體重符合，否則停止。
- 輸液：非新生兒維持量、一次補液、實測流失。另有特定適用條件的新生兒總液體量，不能泛用於NICU。
- 輸血：兒科Hb增幅與血品mL/kg；新生兒另按專用來源。處方時間需人工決定，不直接換算臺灣血品單位。
- 不是完整藥物手冊、復甦流程或處方系統。尚無每日累積劑量追蹤、所有交互作用／禁忌、自動腎調整、幫浦刻度取整、完整管路相容性與長期穩定性資料。
